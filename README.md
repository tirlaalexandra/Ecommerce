### **E-commerce Application (Outdated/Unfinished)**  

This project is an E-commerce web application prototype built using **Angular** for the frontend and **.NET** for the backend. Although the project is incomplete and utilizes outdated technologies, it represents a valuable learning experience and a demonstration of foundational concepts in full-stack web development.  

#### **Key Features Implemented:**  
- **Product Listing:** Displays a catalog of products with details such as name, description, and price.  
- **Shopping Cart Functionality:** Basic implementation of adding products to a cart and updating quantities.  
- **Authentication System:** User registration and login functionality using ASP.NET Identity.  
- **Order Management:** Backend logic for placing and tracking orders.  

#### **Technologies Used:**  
- **Frontend:** Angular (with TypeScript, basic components and routing).  
- **Backend:** .NET Core (REST API, repository pattern).  
- **Database:** SQL Server for storing product, user, and order data.  

#### **Status:**  
The application remains in an unfinished state, with critical features such as payment integration, advanced UI design, and performance optimizations still pending. Additionally, the codebase reflects older standards and may not align with current best practices in Angular or .NET development.  

#### **Purpose:**  
This project served as an opportunity to explore the integration of Angular and .NET for building modern web applications. Despite its limitations, it highlights my ability to structure a full-stack application and my willingness to learn through practical implementation.
